# A303656 — Blocker-Deficient Core Phase B

## Main result

No complete admitted simultaneous C=1 certificate can have at most six
original nonregular prime rows. This holds for unbounded prime sizes, arbitrary
finitely many regular support rows, arbitrary allowed precision and shared
residues, and a sound optional two-adic row.

This is **not** universal C=1 no-go and does **not** solve A303656.
The literal claim that no admitted direct-Hall deficient core exists is false;
the actual boundary singleton is independently checked and then bypassed by
descending guard release.

Start with `REPORT.md` (Chinese, all 15 requested topics), then
`THEOREM_AUDIT.md` (full proofs and counterexample boundaries),
`DEFINITIONS.md`, and `SOURCE_READING.md`.

## Reproduce

Python 3.9+ with the standard library is sufficient. No repository checkout,
external packages, web connection, credentials or database are required.
Run from the extracted package root:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONHASHSEED=0 python3 tools/verify.py
PYTHONDONTWRITEBYTECODE=1 PYTHONHASHSEED=0 python3 -m unittest discover -s tests -v
PYTHONDONTWRITEBYTECODE=1 PYTHONHASHSEED=0 python3 tools/reproduce.py
```

`reproduce.py` uses a temporary output directory by default and compares all
nine deterministic JSON outputs byte for byte. To retain the replay outputs:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONHASHSEED=0 \
python3 tools/reproduce.py --output-dir /tmp/a303656-phase-b-replay
```

It refuses to overwrite the sealed `results/` directory. The recorded test
log contains the runtime of that test execution; it is not regenerated by the
JSON replay and is not a mathematical floating-point comparison.

`verify.py` checks SHA256SUMS.txt against all protected files. The manifest
excludes itself. It is an integrity check, not cryptographic author identity.

## Computation scope

COMPUTATION_SPEC.md froze each domain before its first run. There is no prime
scan, no increasing q_max, and no full-period enumeration for the boundary
resource. Factoring q−1 / cyclotomic integers and checking a single CRT point
are not an enumeration of primes or of the giant exponent period.

The slot-expanding matcher is intentionally a small-domain reference tool;
it is not a memory-optimized production solver for arbitrarily large slot
capacities. The theorem is not limited to the software's frozen audit sizes.
