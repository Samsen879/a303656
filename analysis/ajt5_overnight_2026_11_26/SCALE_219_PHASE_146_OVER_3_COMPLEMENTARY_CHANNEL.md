# Scale 219 fills a phase blocked at scale 73

The normalized phase 146/3 has no native norm at its first odd scale U=73. Every odd admissible V (1 through 105) has an exact odd inert valuation in 25^73−9^V; their compressed divisors are replayed below. Even V is excluded modulo 16. The same normalized phase does occur for coprime (U,V)=(219,115), so a missing first-scale phase does not by itself imply a missing ray at that phase. Label search used a finite sieve and ECM; the supplied whole-modulus half-norm recovery does not require hidden factors or group orders as inputs.

Adding the ray (438,230)·3^k in the (5,3) axes makes 34 certified phases. The unique largest ratio is now 153/145 at (290/9,34), improving the effective lower exponent for the constructed population to 145/306 (previously 71/150), with ε loss in each odd class 3 and 21 mod 24. The ordinary-height positive and failed-label controls below use the same actual exponents. This is not a natural-density or pointwise advance.

## A complementary exact channel on a lower-scale true half

The (73,65) minus half is a true norm even though its plus partner fails at the inert prime 135017. First peel 7 by ordinary modular cubing, leaving h. The component p=415201 in h has an exact threshold B=173 for the stated eight-base smooth rule on that residual: all base orders contain 173, and h−1 lacks it. In contrast the subgroup generated by 2,7,13 has order prime to 3 there, so no smooth bound on those bases will give a nontrivial cubic root.

A different probe works at B=32. In the ring with ω²+ω+1=0, write (3+ω)^(8·lcm(odd ≤32))=x+yω. The gcd of h with N(x+1+yω) gives exactly 415201. The coordinate ratio yields a nontrivial root and converts directly to sqrt(−3). This is explained by the two evaluations of 3+ω having orders 1200 and 415200 at p. A separate plain LCM probe sees the asymmetry at B=32 but has both evaluations equal to 1 at B=173, making the wanted denominator vanish. After removing 415201, the remaining modulus K is caught by the same base 2 using the new K−1 rule; at the previous residual h, h−1 lacks a required factor 227. These are distinct ordinary-order, two-component, and residual-path limitations.

## Full roots and norm recovery

For odd H coprime to 3, any full root of −3 modulo H gives the evaluation ideal in the Eisenstein integer ring of norm H. The ring is principal; a unit makes its generator congruent to 1 modulo 2, so the generator can be written x+y√(−3) with x²+3y²=H. The ideal contains r−√(−3), so the coordinates are primitive. The inequality 2|xy|<H makes the associated approximation to r/H a convergent. The previous Euclidean remainder must exceed √H: otherwise the adjacent convergent determinant would give H≤√H|y|+|xy|≤(√3/2)H. Thus first-remainder Cornacchia recovers the norm, including for the eight CRT sign choices in the actual minus half. No obstruction from a choice between full roots is claimed.

Both new cube orientations are verified modulo 15: net sign sum 0 at even depth, 1 at odd depth, with distinct nonzero mod-5 characters of the two sphere values. The base sine bound 1/11 and cumulative angle deviation <1/32 give the necessary height bound. As in the [33-ray proof](https://github.com/Samsen879/a303656/commit/d8e6eb909b84c6447a581d4ac9083da684329851), two different squarefree kernels avoid the possible single exceptional discriminant in the effective count.

from fractions import Fraction as F
from itertools import product
from math import gcd, isqrt, lcm

N = lambda x,y: x*x+3*y*y
bases = (2,5,7,3,11,13,17,19)

def strip3(n):
    while n%3 == 0:
        n //= 3
    return n

def smooth(B):
    return lcm(*(i for i in range(1,B+1) if i%3))

def cubic(h,b,e,j=0):
    z = pow(b,e*3**j,h)
    d = gcd(h,z*z+z+1)
    assert d>1 and gcd(d,h//d)==1
    return d,(2*z+1)%d

def epow(n,h):
    def mul(a,b):
        x,y = a
        u,v = b
        return (x*u-y*v)%h,(x*v+y*u-y*v)%h
    a,z = (3,1),(1,0)
    while n:
        if n&1:
            z = mul(z,a)
        a = mul(a,a)
        n //= 2
    return z

def recover(H,blocks):
    r,h = 0,H
    for d,z in blocks:
        assert h%d==0 and gcd(d,H//d)==1 and (z*z+3)%d==0
        r += z*(H//d)*pow(H//d,-1,d)
        h //= d
    assert h==1
    r %= H
    assert (r*r+3)%H==0
    a,b = H,min(r,H-r)
    while b*b>H:
        a,b = b,a%b
    c = isqrt((H-b*b)//3)
    assert N(b,c)==H
    return b,c
