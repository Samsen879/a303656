## When two fixed projections can separate

For a subgroup generated by Eisenstein units after two evaluations modulo a split prime, an element is 1 in exactly one evaluation if and only if the two projection kernels differ. If the kernels coincide, the two images identify with the same quotient, and an element has the same order on both sides. In particular the images hit 1 and −1 synchronously. For powers of one generator, the criterion is precisely that its two evaluation orders differ.

N = lambda x,y: x*x+3*y*y
bases = (2,5,7,3,11,13,17,19)

def strip(n,p):
    while n%p==0:
        n //= p
    return n

def smooth(B,p):
    return lcm(*(m for m in range(1,B+1) if m%p))

def cubic(h,b,e,j=0):
    z = pow(b,e*3**j,h)
    d = gcd(h,z*z+z+1)
    assert d>1 and gcd(d,h//d)==1
    return d,(2*z+1)%d

def epow(z,n,h):
    def mul(a,b):
        x,y = a
        u,v = b
        return (x*u-y*v)%h,(x*v+y*u-y*v)%h
    w = (1,0)
    while n:
        if n&1:
            w = mul(w,z)
        z = mul(z,z)
        n //= 2
    return w

def ringraw(h,a,e,eps):
    x,y = epow(a,e,h)
    v = x-eps
    return gcd(h,v*v-v*y+y*y),v,y

def ring(h,a,e,eps):
    d,v,y = ringraw(h,a,e,eps)
