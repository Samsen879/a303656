# Residual-relative exponent captures two new support pages

After removing an existing support D|R, work at Q=R/D. For the prior prime-to-7 smooth exponent L, form C(Q)=(Q−1)_(7′)/gcd((Q−1)_(7′),L). This is computed from Q and does not presume Q is prime or input a large order factor. Reading V_i=W_i^(L C(Q)) in the same saturated gcd test certifies every prime on d₁/d₀ as failed. If no block is caught, the device makes no classification.

Use two words generating the menu-kernel lattice a+kb=0 mod 343; the determinant is 343. On the prime-to-7 group this determinant is invertible, so the subgroup generated by the two word powers includes the original two axis powers. If both captured 7-primary reads are trivial, the kernel relation implies both original projections are 343-torsion and satisfy the ratio k; the first-axis phase E mod 49 must still be checked.

- On previously closed (80,17), using its old D=2216676309079 makes C(Q) equal the certified long factor 3262828345754848069122262531 without using it as an input. The two old reads miss Q and the two new reads are (d₀,d₁)=(1,Q), with relative exponents 340,321. Using C(R) from the whole source still fails to capture that page. The masked powers of the original two axes in the independent exponent box [−4096,4096] have intersection exactly {1}; the small search box in basis directions cannot emulate this on the original mask. This is recertification, not a new closure there.
- On (59,230) the exact original norm is 7R, and the [frozen chart enumerator](https://github.com/Samsen879/a303656/commit/26575f9c2ca06e032a2947555db77561d5840438) gives E≡15 mod49,k=18. Starting with existing D=216123073370947, the two complementary coprime pages yield C(D)=912953 and C(Q)=69534793. Both readings in each page give (1,page), so every prime on each page rejects. This closes this source without needing to certify the two pages as prime. The whole unsplit source's own C(R) captures neither.
- On true (131,173), a composite residual page Q is independently proved composite by its base-2 Fermat failure, and the residual exponent still captures neither direction. On the known prime from (120,220), both ratio-test directions correctly retain it at the calibrated exponent: the direct ratio is satisfied, and the independent first-axis gate fails. There is no general promise for arbitrary residuals or all native sources.

The 2^19 smooth bound never increases. This replay isolates how whole-source versus residual-source inputs change supported factors. The two extra pages of (59,230) were checked by direct powers and gcd, and the supplied optional final SymPy check regenerates its exact raw resultant.

from math import gcd, isqrt, prod

B = 2**19
s = bytearray(b'\1')*(B+1)
s[:2] = b'\0\0'
for i in range(2,isqrt(B)+1):
    if s[i]:
        s[i*i::i] = b'\0'*((B-i*i)//i+1)
parts = []
for i in range(2,B+1):
    if s[i] and i!=7:
        z=i
        while z*i<=B:
            z*=i
        parts.append(z)
L=prod(parts)
assert L%343==104

def extra(n):
    m=n-1
    while m%7==0: m//=7
    return m//gcd(m,L)

def sat(n,d):
    while (e:=gcd(n,d*d))!=d: d=e
    return d

def basis(k):
    u,v=min((abs(u)+v,max(abs(u),v),u,v)
        for v in range(1,172) if v%7
        for u in [(-k*v+171)%343-171])[-2:]
    a,b=min((abs(a)+abs(b),max(abs(a),abs(b)),a,b)
        for a in range(-172,173) for b in range(-172,173)
        if u*b-v*a==343 and (a+k*b)%343==0)[-2:]
    return ((u,v),(a,b))

def read(n,k,J=1):
    out=[]
    for a,b in basis(k):
        W=pow(3,a,n)*pow(5,b,n)%n
        v=pow(pow(W,L,n),J,n)
        d0=sat(n,gcd(v-1,n))
        d1=sat(n,gcd(pow(v,7**n.bit_length(),n)-1,n))
        out.append((v,d0,d1))
    return out

def support(rows):
    return [(a,b) for _,a,b in rows]
