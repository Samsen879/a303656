# Recover 7-primary axis components on composite capture support

Let gcd(R,105)=1, let L be the specified 7-free lcm, H=7^bitlength(R), and Z(u,v)=(3^u 5^v)^L modulo R. Saturating d by repeated gcd(R,d²) retains precisely the full prime-power factors whose prime divides d; the exponent at least doubles each round until full. Define C_R(a,b) by saturating gcd(R,Z(a)^H−1,Z(b)^H−1). This represents common support prime by prime, not a claim that the power equalities necessarily hold modulo each full prime power.

Fix a word a nonzero mod 7 and b with t=v_7(det(a,b)) finite. Choose c so b−ca is divisible in both coordinates by 7^t; compute the actual word w=(b−ca)/7^t. Then C_R(a,w)=C_R(a,b): at each prime captured by a, Z(b)^H=(Z(w)^H)^(7^t), while Z(w)^H has order prime to 7. The determinant of a,w is a 7-unit. Repair after fixing a pair thus preserves the pair's common support. Changing the pair itself may lose support.

On the common composite block C, write a=(u,v), w=(i,j), Δ=uj−vi and d=Δ^(-1) mod H. Then modulo each prime factor of C the residues
```
A = (Z(a)^j Z(w)^(-v))^d
B = (Z(a)^(-i) Z(w)^u)^d
```
are the 7-primary components of the two axis reads. This follows by applying the adjugate to the two original word values in each prime's 7-primary group. The common block where both components have order at most 343 is the saturation of gcd(C,A^343−1,B^343−1). The complement cannot enter a chart requiring the original order-343 model. On the low block, testing a coarse tag (e,k) requires A^7=x^(7Le) and B=A^k, with native root x of order 343; for the chart's unit e these tests determine the coarse label. The order test requires the unprojected word values, not just the gcd probes.

## Genuine composite positive and support-loss control

For the true source (16,186), the first word (2663,260) alone captures both prime factors in C, but adding (−3,−1) retains only the higher-order factor. Its division repair (380,37) preserves exactly that smaller support. A different actual pair (3799,−1686),(−177,5125) jointly captures the full C, and division gives (−568,973) without loss. The reconstructed axes have exact order 343 at 332548023739 and exact order 7^5 at 572493630662019608249, computed from the composite block before using either factor as input. The low block rejects the tested coarse tag (29,172) in both identities. This is a finite exact source/control and a factor-free way to read a captured block; it does not guarantee that a suitable short pair exists on every remaining factor.

```python
from math import gcd, isqrt, prod

R = 21831913108948893248715238773608846587809381120739
x = 15291813246895535008829559404479309226462829871765
assert gcd(R,105)==1 and pow(x,343,R)==1 and gcd(R,pow(x,49,R)-1)==1
assert (1-x+pow(x,16,R)-pow(x,186,R))%R==0

K=2**19
s=bytearray(b'\1')*(K+1)
s[:2]=b'\0\0'
for a in range(2,isqrt(K)+1):
    if s[a]:
        s[a*a::a]=b'\0'*((K-a*a)//a+1)
def pp(a):
    b=a
    while b*a<=K:
        b*=a
    return b
L=prod(pp(a) for a in range(2,K+1) if s[a] and a!=7)
H=7**R.bit_length()
U,V=(pow(a,L,R) for a in (3,5))

def sat(n,d):
    while (g:=gcd(n,d*d))!=d:
        d=g
    return d
def z(w,n):
    return pow(U,w[0],n)*pow(V,w[1],n)%n
def cap(*W):
    return sat(R,gcd(R,*(pow(z(w,R),H,R)-1 for w in W)))

old,b0,d0=(2663,260),(-3,-1),(380,37)
assert tuple(a+b for a,b in zip(old,b0))==tuple(7*d for d in d0)
top=cap(b0)
assert top==cap(old,b0)==cap(old,d0)==572493630662019608249

a,b,w=(3799,-1686),(-177,5125),(-568,973)
assert a==(-2*(-1869)+61,-1869+3*61)
assert b==(-2*808+1439,808+3*1439)
assert tuple(y-x for x,y in zip(a,b))==tuple(7*d for d in w)
C=cap(a,b)
assert C==cap(a,w)==cap(old)==190381625479819594969671932223011
u,v=a
i,j=w
D=u*j-v*i
assert D==2738779 and gcd(D,7)==1
d=pow(D,-1,H)
A=pow(pow(z(a,C),j,C)*pow(z(w,C),-v,C)%C,d,C)
B=pow(pow(z(a,C),-i,C)*pow(z(w,C),u,C)%C,d,C)

p=sat(C,gcd(C,pow(A,343,C)-1,pow(B,343,C)-1))
assert p==332548023739 and C==p*top
for z7 in (A,B):
    assert [gcd(C,pow(z7,7**t,C)-1) for t in (2,3,4,5)]==[1,p,p,C]
assert gcd(p,pow(A,7,p)-pow(x,7*(L%343)*29,p))==1
assert gcd(p,B-pow(A,172,p))==1
assert R//C==114674475826781249 and R%C==0

for n,fs in ((p,[2738779]),(top,[643,93601,195971]),(R//C,[1914208031])):
    f=prod(fs)
    assert f*f>n and (n-1)%f==0
    for q in fs:
        assert all(q%d for d in range(2,isqrt(q)+1))
        assert any(pow(a,n-1,n)==1 and gcd(pow(a,(n-1)//q,n)-1,n)==1 for a in range(2,50))
print("PASS")
```

The constant R can additionally be regenerated by the exact SymPy equality
`resultant(sum(z**i for i in range(0,343,49)), 1-z+z**16-z**186,z)==7*R`.
