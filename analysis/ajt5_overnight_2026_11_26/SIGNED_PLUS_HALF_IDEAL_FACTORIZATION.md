# Signed ideal factorization of the plus half in Q(sqrt(-15))

The two exact orders give a signed factorization in \(\mathbb Q(\sqrt{-15})\). Each witness has two conjugate prime ideals above it, and the actual \(5/3\) order selects exactly one. At \(\ell=23\), conjugating just one witness factor preserves the integer norm and breaks the factorization. The same construction gives an exact gcd rule that explains why smaller-index norms cannot supply a primitive witness.

### An exact factorization for the plus half

Write \(r=\sqrt{-15}\). For odd \(t=2n+1\), put \(e=(-1)^n\) and
\[
\alpha_t=A_t+B_t r,\qquad
A_t=\frac{5^{n+1}+e3^{n+1}}8,\quad
B_t=\frac{3^n-e5^n}8.
\]
Both coordinates are integral. The identities
\[
A_t+5eB_t=e3^n,\qquad A_t-3eB_t=5^n
\]
give \(\gcd(A_t,B_t)=1\) and
\[
(5+er)\alpha_t=5^{n+1}+3^n r,\qquad
N(\alpha_t)=\frac{5^t+3^t}{8}=H_t.
\]
For every prime \(q\mid H_t\), the prime ideal dividing \((\alpha_t)\) is the one defined by
\[
r\equiv \rho_t(q):=-5^{n+1}3^{-n}\pmod q.
\]
Indeed \(\rho_t(q)^2=-15\bmod q\), and the displayed element identity selects this root. Primitivity excludes the conjugate ideal. In particular, when \(t=\ell>5\) is prime, \(5/3\) has exact order \(2\ell\) at both witnesses, and the formula fixes both signs.

Under the full hypothesis \(H_\ell=d s^2q_1q_2\), with \(d=6\ell+1\) and \(q_1,q_2\) distinct inert primes, this gives the element identity
\[
\boxed{\quad \kappa\alpha_\ell
=\pm\delta\,\frac{z_1z_2}{3}\,w^2,\qquad
N(\delta)=d,\quad N(z_i)=3q_i,\quad N(w)=\kappa s .\quad}
\]
Here \(\delta\) generates the selected prime ideal over \(d\), and \(z_i\) generates the selected ideal over \(q_i\) multiplied by the ramified ideal over \(3\). The correction is \(\kappa=1\) when \(s\equiv1\bmod3\) and \(\kappa=3\) when \(s\equiv2\bmod3\).

The class-group calculation is short. The Minkowski bound is \(2\sqrt{15}/\pi<3\). The two ideals over \(2\) have inverse classes, and one squares to the ideal generated by \((1+r)/2\), whose norm is \(4\). There is no element of norm \(2\), so the class group has order two. The ramified ideal \(\mathfrak p_3\) represents the nontrivial class because there is no element of norm \(3\). For a split prime of odd norm \(q\ne3,5\), a principal generator forces \(q\equiv1\bmod3\). A generator after multiplication by \(\mathfrak p_3\) has norm \(3q\) and forces \(q\equiv2\bmod3\). Thus the ideal of norm \(s\) is principal exactly when \(s\equiv1\bmod3\). In the other class, multiplying it by \(\mathfrak p_3\) and using \(\mathfrak p_3^2=(3)\) gives the factor \(w^2/3\). Taking norms in the boxed identity recovers the full integer factorization. [Minkowski’s ideal-class bound](https://www.math.ucla.edu/~sharifi/notes/algnum-ch04.html)

### What smaller-index norms can supply

For odd \(m,t\) and \(g=\gcd(m,t)\), the rational gcd is \(H_g\). At each odd prime power this follows from the order of \(-5/3\): its \(m\)-th and \(t\)-th powers both equal \(1\) exactly when its \(g\)-th power does. At a prime dividing \(H_g\), the selected root for \(m\) differs from the one for \(g\) by \((-1)^{(m/g-1)/2}\). Consequently the ideal gcd is \((\alpha_g)\) when both quotients are \(1\bmod4\), \((\overline{\alpha_g})\) when both are \(3\bmod4\), and the unit ideal when the phases differ.

For prime \(\ell\), every smaller odd index has \(g=1\) and \(H_g=1\). This rules out extracting a primitive witness by taking gcds with those smaller norms. The signed factorization provides an exact certificate once candidate prime norms are available. It gives neither a small-witness bound nor a new admissible seed family.

### Exact \(25,9\) replay

At \(\ell=23\), the signed factors are \(\delta=2-3r\), \(z_1=9+2r\), and \(z_2=179913+208472r\). At \(t=23\cdot47\), the actual \(47\)-part moves to the conjugate ideal and has valuation two. Its generator \(7-12r=(9-2r)^2/3\) illustrates why the class correction is needed. Its ideal square root is nonprincipal.

```python
from math import isqrt

def norm(z):
    return z[0]**2 + 15*z[1]**2

def conj(z):
    return z[0], -z[1]

def mul(z, w):
    a,b = z
    c,d = w
    return a*c-15*b*d, a*d+b*c

def divides(z, w):
    return all(a % norm(z) == 0 for a in mul(conj(z), w))

def alpha(t):
    n = (t-1)//2
    e = (-1)**n
    return (5**(n+1)+e*3**(n+1))//8, (3**n-e*5**n)//8

a = alpha(23)
delta,z1,z2 = (2,-3),(9,2),(179913,208472)
assert mul(delta,mul(z1,z2)) == tuple(3*x for x in a)
assert norm(a) == 139*47*228092436443 == (5**23+3**23)//8
assert 25**23-9**23 == 8*(5**23-3**23)*norm(a)

for q,z,k in [(139,delta,1),(47,z1,3),(228092436443,z2,3)]:
    assert all(q % j for j in range(2,isqrt(q)+1))
    assert norm(z) == k*q
    x = 5*pow(3,-1,q) % q
    assert x != q-1 and pow(x,23,q) == q-1
    rho = -pow(5,12,q)*pow(pow(3,11,q),-1,q) % q
    assert (z[0]+z[1]*rho) % q == 0
    assert (z[0]-z[1]*rho) % q != 0

assert norm(mul(delta,mul(z1,conj(z2)))) == 9*norm(a)
assert not divides(conj(z2),tuple(3*x for x in a))

b = alpha(23*47)
theta = (7,-12)
assert mul(conj(z1),conj(z1)) == tuple(3*x for x in theta)
assert divides(conj(a),b) and not divides(a,b)
assert divides(theta,b) and norm(b) % 47**3 != 0
```

Independent BigInt reproduced all three signed factors, an equal-norm conjugated factor that fails division, and the order-controlled conjugate ideal at index 23×47. The identity certifies candidate factors; it does not construct a new seed family or bound the least witness.
