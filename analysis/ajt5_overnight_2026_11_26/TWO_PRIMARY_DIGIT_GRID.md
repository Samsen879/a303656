# Two-primary-digit grid test for a finite inert-prime blocker

Use the paired exponent phases of [the first-blocker tail](FIRST_FINITE_LOCAL_BLOCKER_TAIL.md), with bases \(A=3^{120}, B=5^{3240}\) in the two exponent indices and pair multiplier \(\kappa=3^{24}\). Work at non-support inert primes, so the two endpoint roots at each phase are distinct modulo the prime and \(2,3,5\) are in the fixed support. This is a local criterion, not an integer representation theorem.

Fix a candidate last prime \(q\). Pick \(r^{h+1}\mid\operatorname{ord}_q(A)\) and \(\ell^{k+1}\mid\operatorname{ord}_q(B)\), with \(r,\ell\) prime. In a common starting phase, add \(xr^h\) in the \(r\)-primary coordinate of the first index and \(y\ell^k\) in the \(\ell\)-primary coordinate of the second, for \(0\le x<r,\ 0\le y<\ell\). The two coordinates can be varied independently also when \(r=\ell\). Write the paired shifts in this grid as \(U_x+V_y,\ \kappa U_x+V_y\).

## What an older prime can delete

For \(p\ne r,\ell\), variation on the first axis is read exactly when \(r^{h+1}\mid\operatorname{ord}_p(A)\), and similarly for the second axis. This is true simultaneously at all depths because lifting the order from \(p\) to \(p^j\) only adds \(p\)-power factors. An axis read this way takes distinct values modulo \(p\) across its variants.

- If neither is read and the starting phase passes, all variants pass.
- If only one axis is read, only up to two of its coordinate indices can hit a root. Conservatively remove their entire rows or columns.
- If both are read, each endpoint equation cuts out a partial matching in the grid. At most two edges per row or column can be removed; checking exact odd valuation can only reduce the deleted edges. A double-reading prime must be \(1\bmod\operatorname{lcm}(r^{h+1},\ell^{k+1})\), not necessarily \(1\) modulo the product.

Handle any old primes \(p=r,\ell\) separately by their exact local conditions. In particular they need not preserve a rectangular set. If \(r=\ell=p\) and both axes first change at the same odd depth, the next residual digit is affine in \(x,y\bmod p\) with both coefficients nonzero by lifting the unit powers. For a near-root starting phase, the only surviving candidates are on the zero line of that affine digit, and even those must be tested at higher depth.

## A capacity inequality and exact final-prime filter

Suppose the handling of old primes leaves a guaranteed \(a\times b\) rectangle apart from \(m\) ordinary double-reading primes and at most \(d\) extra partial matchings. At \(q\) both axes are injective. Put \(\beta=1\) if \(\kappa\) is not in the subgroup generated by the ratio of two consecutive \(U_x\) values modulo \(q\), and \(\beta=2\) otherwise. Each row has at most two possible \(q\)-deletions, and each column at most \(\beta\): two roots in one column would require two first-axis values of ratio \(\kappa\). Thus full blocking of the rectangle requires
\[
 ab-\min(2a,\beta b)\le (2m+d)\min(a,b),\quad
 b\le 2m+d+2,\quad a\le 2m+d+\beta.
\]
This holds for any certified residual rectangle; it does not require estimating the losses from separate axis slices as independent.

For the exact final-prime test, set \(\lambda=\min(v_q(3^{q-1}-1),v_q(5^{q-1}-1))\). Neither \(q\)-primary index is read by any old prime or by the fixed support conditions: the support exponents' fixed steps were chosen in advance, and the old non-support prime orders have no \(q\) factor at any depth. At each selected variant the fastest \(q\)-primary unit-power change fills its shifted residue ball modulo \(q^\lambda\), by the cyclic principal-unit group (the step sizes are units at \(q\)). If the collided residual lies in that ball, we can arrange an even valuation without changing old conditions. If it lies outside, its valuation is fixed. Therefore a \(q\)-block of the selected old survivors can be checked by intersecting the conditions that each has a residual of odd valuation below \(\lambda\).

Distinct grid points have different unordered pairs of first roots: equal pairs would force \((\kappa-1)U_x=\pm(\kappa-1)U_{x'}\). The minus sign is impossible since the first-axis group has odd order (the exponent step is even), and the plus sign forces \(x=x'\) and then \(y=y'\). For at least two survivors this leaves at most one common root modulo \(q\). At \(\lambda=2\), given a common root, the obstruction occurs at exactly \(q-D\) classes modulo \(q^2\) above it, where \(D\) counts the distinct corresponding endpoint lifts at depth two. These are the lifts different from every endpoint. To certify a full blocker rather than blockage of this grid, phases outside it also need checking.

## Replays

At \(43\), both axes read the same 7-primary digit even though \(49\nmid42\). There are 14 actual bad pairs; the \(5\times5\) product of two individually surviving axis slices still contains six bad pairs. The second example at \(31\) checks the common-primary odd-depth line, and the behavior of its points at \(311\).

~~~python
from collections import Counter
from math import lcm, prod

p, q = 43, 127
E = lcm(6*p, 18)
n = 2839290121353869
M = 32*prod((3,5,7,11,13,41,73,6481))
assert n % M == 5957011386509 and n % p**2 == 0

def order(a, p):
    return next(j for j in range(1,p) if pow(a,j,p) == 1)

assert [order(pow(a,k,p),p) for a,k in ((3,120),(5,3240))] == [7,7]
assert [order(pow(a,k,q),q) for a,k in ((3,120),(5,3240))] == [21,7]
assert pow(3,24*7,q) == 107  # q 的每列至多一个根

def off(x,y,j,m):
    return (pow(3,21+120*E*x+j,m)+pow(5,42+3240*E*y,m)) % m

bad = set()
for x in range(7):
    for y in range(7):
        u = [off(x,y,j,p*p) for j in (0,24)]
        assert all(u)
        if any(v % p == 0 for v in u):
            bad.add((x,y))
assert Counter(x for x,y in bad) == Counter(y for x,y in bad) == dict.fromkeys(range(7),2)
I = {x for x in range(7) if (x,1) not in bad}
J = {y for y in range(7) if (0,y) not in bad}
assert len(bad) == 14 and len(I) == len(J) == 5
assert sum((x,y) in bad for x in I for y in J) == 6

def root(x,y,j,m):
    return (pow(3,26+120*x+j,m)+pow(5,50+3240*y,m)) % m

assert all(root(x,y,0,31**2) == (229+31*(15*x+27*y)) % 31**2
           for x in range(31) for y in range(31))
freq = Counter(root(x,(1-15*x)*pow(27,-1,31)%31,j,311)
               for x in range(31) for j in (0,24))
assert max(freq.values()) == 2

~~~
