# P2：低分圆块的分层必要条件

**P2 的低块限制可以加强到分层结论。** 在 \((a,b)\equiv(22,4)\pmod{720}\)、\(11^r\mid a-1,b+2\)、\(r\ge3\) 的平衡族上，\(2\)-进深度为 \(1\) 的一侧必须取得原始块的非平凡因子。另一侧的最迟可用块取决于 \(3\) 落在哪边。两侧原始块因子的模 \(11\) 二次字符必相反，但哪一边为负可以改变。

### 无需枚举的分层证明

令 \(A=3^a,\ B=5^b\)，\(X=3^{(a-1)/11^r},\ Y_0=5^{(b+2)/11^r}\)，并记
\[
D_0=(X+Y_0)/4,\qquad
D_j=\frac{X^{11^j}+Y_0^{11^j}}{X^{11^{j-1}}+Y_0^{11^{j-1}}}\quad(j\ge1).
\]
前两条平方的半根给出 \(uv=d=24D_0D_1\cdots D_r\)，其中
\[
d=2(A+75B),\quad e=20A+25B,\quad f=182A-6B.
\]
每个 \(D_j\) 的素因子都等于 \(1\bmod 6\cdot11^j\)。任一侧的 \(2,3\) 部分 \(k\) 属于 \(\{2,4,6,12\}\)。若该侧只取第 \(h\) 层及以上的块因子，则该侧等于 \(k\bmod11^h\)。

令
\[
G(x)=(x+d/x)^2-4e,\qquad J(x)=(x+d/x)^2-4f.
\]
本指数族上 \((d,e,f)\equiv(543,86,44)\pmod{1331}\)。直接代入四个 \(k\)，得到以下必要条件。

| 该侧的 \(k\) | \(G(k)\bmod1331\) | 必须取得非平凡因子的块范围 |
|---:|---:|---|
| \(2,6\) | \(255,1315\)，模 \(11\) 为非平方 | \(D_0\) |
| \(12\) | \(22\)，恰有一层 \(11\) | \(D_0D_1\) |
| \(4\) | \(968=8\cdot121\)，单位 \(8\) 为非平方 | \(D_0D_1D_2\) |

模 \(11\) 下有 \(d=4,e=9,f=0\)，且 \(G(x)=(x^2-1)(x^2-16)/x^2\)。直接代入模 \(11\) 的平方类 \(x^2=1,3,4,5,9\)，得到 \(G\) 可平方仅当 \(x\equiv\pm1,\pm4\)。这时 \(x+d/x\equiv\pm5\)，所以 **\(J(x)\) 自动是 \(11\)-进单位平方**。更高精度只检查 \(G\) 在四个简单根中相应一根的距离。具体地，若根为 \(\rho\) 且 \(x\ne\rho\)，则 \(v_{11}(G(x))=v_{11}(x-\rho)\)，其单位字符由 \(G'(\rho)\) 与 \(x-\rho\) 的首个非零数字决定。两个精确因子共享同一个 \(G\)，因为 \(G(d/x)=G(x)\)。

又因 \(D_0\equiv d/24\equiv2\pmod{11}\)，两侧取走的 \(D_0\) 因子的字符乘积为 \(-1\)。因此恰有一侧承担负字符，且该侧必含一个以奇次幂分配、模 \(11\) 为非平方的原始块素因子。

### 可重放的局部控制

使用实际指数 \((a,b)=(104835635303242026939780982,71561454060866653033675204)\)，取 \(v=4\cdot727\)。素数 727 首次出现在第二层，精确互补因子 \(u=d/v\) 在同一对指数上计算。两条剩余量在模 1331 的读数分别为 121、289，在模 727 下分别为 272、418（两者都是非零二次剩余）。这说明这两个局部素数读数本身不排除使用第二层且不使用第零、第一层的 \(k=4\) 一侧。没有声称两条剩余量为整数平方，也没有声称该短因子处于原普通高度窗口。

```python
P=1331
def leg(x,p):
    x%=p
    return 0 if x==0 else (1 if pow(x,(p-1)//2,p)==1 else -1)
def values(a,b,m):
    A,B=pow(3,a,m),pow(5,b,m)
    return (2*(A+75*B)%m,(20*A+25*B)%m,(182*A-6*B)%m)
assert all(pow(base,1210,P)==1 for base in (3,5))
# Exponents are fixed modulo lcm sets only as far as residues here require:
assert all(pow(base,720*P,P)==1 for base in (3,5))
a,b=104835635303242026939780982,71561454060866653033675204
assert (a%720,b%720)==(22,4)
assert ((a-1)%P,(b+2)%P)==(0,0)
D,E,F=values(a,b,P)
assert (D,E,F)==(543,86,44)
assert {k:((k+D*pow(k,-1,P))**2-4*E)%P for k in (2,6,12,4)}=={2:255,6:1315,12:22,4:968}
assert [x for x in range(1,11) if leg((x+D*pow(x,-1,11))**2-4*E,11)>=0]==[1,4,7,10]
assert all(leg((x+D*pow(x,-1,11))**2-4*F,11)==1 for x in (1,4,7,10))
q=727
x,y=(a-1)//P,(b+2)//P
for j in [0,1]: assert (pow(3,x*11**j,q)+pow(5,y*11**j,q))%q
assert (pow(3,x*11**2,q)+pow(5,y*11**2,q))%q==0
v=4*q
for mod in (P,q):
    dt,et,ft=values(a,b,mod*v)
    assert dt%v==0
    u=dt//v
    G,J=((v+u)**2-4*et)%mod,((v+u)**2-4*ft)%mod
    print(mod,u,G,J)
    if mod==P: assert (G,J)==(121,289)
    else: assert u==6 and leg(G,q)==leg(J,q)==1
print("OK")

```
