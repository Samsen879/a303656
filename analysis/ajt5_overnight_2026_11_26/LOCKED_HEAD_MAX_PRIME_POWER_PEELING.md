# 锁定小头部后的最大阶素数幂剥离

锁定模 \(3960\) 的小头部后，可以按**最大的阶素数幂**剥离共同 Wieferich 终端。最难的一支是普通素数 \(r\) 的两轴都被终端读取。此时旧行把两个相位位锁在一条仿射线上，每个终端通常只排除 \(O(\sqrt r)\) 个点。唯一能覆盖整条线的情形要求两个乘法特征同频、系数恰好抵消。这个例外给出了首个共同 Wieferich 终端的 \(\beta_q/r^2\) 概率上界。没有得到新的全尾总数，原问题的既有例外密度上界仍沿用 **\(0.0876\%\)**；本文不宣布数值改进。

## 锁头部后的剥离定理

写 \(S(c,d)=3^c+5^d\)，并令 \(o_b(p)=\operatorname{ord}_p(b)\)、\(e_b(p)=v_p(b^{p-1}-1)\)。固定已经通过小头部的 \(c,d\bmod3960\)。考虑任意有限惰性素数面板 \(P\subset\{p>23\}\)。称至少一个 \(e_b(p)=1\) 的行为普通行，称这样的底数为快轴。设 \(E\) 是面板中两轴均有 \(e_b(p)\ge2\) 的终端。终端的剥离目标是 \(n-S\not\equiv0\bmod q\)。

在当前剩余终端 \(E'\) 的两底阶中，取数值最大的单个素数幂 \(D=r^a\)，令 \(G\) 为至少一轴读取 \(r^a\) 的终端。若 \(r\) 为奇数且 \(a>v_r(3960)\)，可采用以下规则。

| 枢轴条件 | 足以剥离 \(G\) 的条件 |
|---|---|
| \(r\) 不是面板中的普通行，或 \(a\ge3\) | \(|G|<r\) |
| \(r\) 是普通行且 \(a=2\) | \(|G|+1<r\) |
| \(r\) 是普通行且 \(a=1\)，有一条快轴在 \(G\) 的所有终端均不读 \(r\) | \(|G|<r\) |

若反复剥离能删空 \(E\)，则**对每个**通过固定小头部的局部目标，同时存在一个相位，使所有终端都是单位、所有普通行的赋值都是 \(0\) 或 \(2\)。

证明从空终端集开始，按素数递增修普通行，再逆序加回各组。加回 \(G\) 时，两轴各改变一个 \(r^{a-1}\) 位，得到 \(r\times r\) 网格。留下的终端不读取这个位。设 \(M\) 为当前终端阶中最大的素因子，任一普通 \(p\le M,\ p\ne r\) 的两底阶均整除 \(p-1<D\)，也不读取这个位。每个 \(q\in G\) 至少在一轴上单射，因此至多排除 \(r\) 格。若普通行 \(r\) 有 \(a\ge3\)，其模 \(r^3\) 读数不变。若 \(a=2\)，旧赋值为 \(2\) 时至多再排除一条模 \(r\) 直线，快轴保证这条线的方程非退化。有未读快轴时，先在另一轴避根，再用快轴修 \(r\)。最后按递增顺序重修 \(p>M\) 的普通行。它们各自的素数位不被任何当前终端读取。这些操作都保留模 \(3960\) 的头部。

自由位条件对真实共同 Wieferich 终端的最大阶素数幂自动成立。若 \(q>23\) 的两底阶中所有素数幂都至多 \(11\)，因 \(q\equiv3\bmod4\)，两阶都整除 \(6930\)。共同 Wieferich 条件将给出 \(q^2\mid\gcd(3^{6930}-1,5^{6930}-1)\)，而该最大公因数只有 \(2,7,11\) 带平方因子。下方脚本精确核验。这个结论无需借用共同 Wieferich 搜索截止。

## 两条快轴都被读取时

设 \(D=r\)，且 \(r\) 的两轴都是快轴。固定其他相位位。若 \(n\not\equiv S\bmod r\)，旧行是单位，仍可用整个网格。否则，要通过旧行，两个低位 \(t,s\in\mathbb F_r\) 必须满足
\[
s=s_0+\lambda t,\qquad \lambda\ne0.
\]
线上每点都能用下一位修到旧行的精确赋值 \(2\)。当前终端只读 \(r\) 的第一位。

只读一轴的终端在线上至多排除一点。读双轴时，终端读数可写成 \(Az+Bz^m\)，其中 \(z\) 遍历 \(\mathbb F_q^\times\) 的 \(r\) 阶子群，\(A,B\ne0\)。若 \(m\ne1\bmod r\)，同一纤维中每个非平凡有序比值 \(\rho\) 至多出现一次。固定 \(\rho=z'/z\) 后，两个纤维方程是关于 \(z,z^m\) 的线性系统，其行列式含非零因子 \(\rho^m-\rho\)。因此纤维大小 \(k\) 满足 \(k(k-1)\le r-1\)。若 \(m=1\)，读数或者单射，或者恒为零。后者对每个终端至多发生在一个截距 \(s_0\)。锁定奇偶还给出一个直接筛选：若 \((3/q)^c(5/q)^d=1\)，则 \(3^c+5^d\equiv0\bmod q\) 不可能。

令 \(K_r=\lfloor(1+\sqrt{4r-3})/2\rfloor\)。只要没有与目标零值相撞的恒零终端，且各终端的排除数上界之和小于 \(r\)，这一组便可同时避根。逐行用统一上界时，\(r\ge113\) 足以处理同组至多十个终端。这个结论有明确的同频检查和枢轴条件，未覆盖任意十个锁头部终端。

**首终端的概率收益。** 若 \(q\) 是算术顺序上第一个真正的共同 Wieferich 素数，并且其最大阶素数幂是上述 \(r\)，先修 \(p<r\) 的普通行，不读取 \(n\bmod r^2\) 或 \(n\) 的 \(q\)-进分量。能让 \(q\) 成为首个阻断的 \(n\bmod r^2\) 至多一类。发生恒零时，两轴的阶根唯一提升到模 \(q^e\)，其中 \(e=\min(e_3(q),e_5(q))\)，所以抵消持续到模 \(q^e\)。只有 \(v_q(n)\) 是小于 \(e\) 的奇数时，\(q\) 的自身坐标才无法修好。因此在固定上述边界后，
\[
\Pr(q\text{ 首次阻断})\le \frac{1}{r^2}
  \frac{1-q^{-2\lfloor e/2\rfloor}}{q+1}
  =\frac{\beta_q}{r^2}.
\]
两个概率因子来自不同素数的 CRT 坐标。若已有更早的异常行读取这些位，这个证明不能直接收费。

## 同一个整数上的真 \(3,5\) 正反控

固定 \((c,d)\equiv(8,55)\bmod3960\)。下面构造一个实际整数 \(N\)，在 \((8,55495)\) 有显式正平方和余量，且 \(v_{31}(N-S)=2\)。

- **\(683\) 的避根失败覆盖整个锁定状态。** \(683\) 的阶为 \((31,682)\)。用 \(i,j\bmod31\) 表示两轴在锁定后的自由位。旧 \(31\) 行可通过的投影恰为 \(j=14+20i\bmod31\)，而 \(S\equiv N\equiv0\bmod683\) 也恰在这条线上。更高位无法避开这个根。实际锚的 \(683\)-赋值恰为 \(2\)，所以这个避根失败与真正范数相容。
- **\(5023\) 在同一点避根成功。** 它的阶为 \((5022,162)\)，在 \(31\) 只读 \(3\) 轴。保留 \(5\) 轴修旧行后，实际锚给出 \(S\equiv625\not\equiv N\bmod5023\)。

两个终端都是普通素数。它们检验的分别是整条低位直线上的抵消和未读轴修复。旧状态有显式真范数见证，且所有枚举格都在同一个 \(N\) 的正余量窗内。

```python
from itertools import product
from math import gcd, isqrt, prod

def prime(p):
    return p > 1 and all(p % k for k in range(2, isqrt(p)+1))

def order(b, p):
    return next(k for k in range(1, p) if pow(b, k, p) == 1)

def S(c, d, m):
    return (pow(3, c, m) + pow(5, d, m)) % m

ps = (19,23,31,43,61,67,71,127,181,199,211,331,421,463,
      631,661,883,991,2311,4621,34651)
assert all(map(prime, (2,7,11)+ps))
assert gcd(3**6930-1, 5**6930-1) == 8*7**2*11**2*prod(ps)

C, r, q, Q = 3960, 31, 683, 5023
assert all(prime(p) and p % 4 == 3 for p in (r,q,Q))
assert [tuple(order(b,p) for b in (3,5)) for p in (r,q,Q)] == [
    (30,3), (31,682), (5022,162)]
assert [pow(b,30,31**2) for b in (3,5)] == [528,280]
assert all(any(pow(b,p-1,p*p) != 1 for b in (3,5)) for p in (q,Q))

x = 878689324483835865 + 1818491925553156392*5**(55+30*C)
y = 764664689757674474
R = x*x + y*y
N = 3**8 + 5**55495 + R
assert N > 3**(8+30*C) + 5**(55+30*C)
assert N%8 == 3 and N%q == N%Q == 0
assert all((N-S(8,55,p))%p == 1 for p in (3,7,11,19,23))
assert R%r**3 == r*r and R%q**3 == q*q
assert S(8,55495,Q) == 625

for i,j in product(range(r), repeat=2):
    c,d = 8+C*i, 55+C*j
    assert (N-S(c,d,r))%r == 0
    line = (j-14-20*i)%r == 0
    assert ((N-S(c,d,r*r))%(r*r) == 0) == line
    assert (S(c,d,q) == 0) == line
print("OK")
```

这次的概率收益只覆盖上述可识别的首终端分支。全尾仍需控制更早异常行与当前枢轴重叠的情形。有限相位结论经既有归约用于双增长指数盒的漏报密度，原猜想的逐点问题仍开放。[单见证有限阻断归约](https://github.com/Samsen879/a303656/blob/67fde350af013a3183e4e7ec6411a016522b7ad6/analysis/ajt5_overnight_2026_11_26/SINGLE_WITNESS_FINITE_OBSTRUCTIONS.md)
