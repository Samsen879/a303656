# Fixed local panels cannot certify every genuine label in a phase interval

Assume a passing periodic exponent class U=a, V=b mod M where M is even, a,b odd and gcd(a,b,M)=1. Such a class can retain prescribed residues or exact valuations at a fixed finite panel. Choose an inert prime p outside the panel, p≡−1 mod 12M (Dirichlet). The subgroup generated by 25 and 9 mod p has order d dividing (p−1)/2, prime to M. For a generator g write 25=g^x, 9=g^y and set U=y, V=x mod d. This forces collision modulo p and gcd(x,y,d)=1.

Let s=min(v_p(25^d−1),v_p(9^d−1)), and take the smallest odd k≥s. If the first valuation attains s, take V=1 mod p^(k+1) and choose U so (25^d)^U=9^d(1+p^k) mod p^(k+1). This is possible because 25^d generates the subgroup 1+p^s modulo p^(k+1), by binomial lifting for odd p (if s=k+1 the subgroup would be trivial, but k≥s). Exchange axes if the second attains s. With the mod-p collision and d prime to p, taking dth powers does not change the difference valuation, which is now exactly k. The combined CRT class has gcd(U,V,Mdp^(k+1))=1 by the three separate constraints. This does not assume p is non-Wieferich for either base.

For final combined modulus N and a nonempty positive open phase interval choose integers r,t with 2Nt/3^r in the interval and t≥1. With U=tV+c and c chosen nonzero to respect the CRT residues, put V=b'+N(3^j+e_j). A bounded CRT choice of e_j ensures V=1 at primes dividing c but not N; the other possible common primes are already ruled out by the primitive class. Both exponents grow, 5^U>3^V for large j, and normalized phase tends to 2Nt/3^r. The new odd inert valuation persists. Thus no rule using only a fixed passing periodic class can certify all its actual primitive pairs, even inside an open phase interval. This does not obstruct genuine construction identities or local tests whose panel grows with the label.

The replay gives two true growing phase-gap trajectories retaining a fixed panel while v_23=1, a small same-panel finite counterexample, and an exact *positive* negative-half norm for (231,131). The latter's positive half remains unresolved, so no new double-norm ray is certified.

```python
from fractions import Fraction as F
from math import gcd,isqrt

def val(n,p):
    e=0
    while n%p==0:
        n//=p
        e+=1
    return e

def counter(u,v):
    D=25**u-9**v
    return (D>0 and gcd(u,v)==1
            and all(val(D,p)%2==0 for p in (2,5,11,17))
            and val(D,23)==1)

assert min((u,v) for u in range(1,14,2) for v in range(1,2*u,2)
           if counter(u,v))==(13,7)
A,S=5**13,3**7
assert [val(A*A-S*S,p) for p in (2,5,11,17,23)]==[6,0,0,0,1]
assert val(A+S,23)==1 and (A+S)//8==152588164

panel=32*11*17
assert pow(25,40,panel)==pow(9,40,panel)==1
assert 401%40==1 and (pow(25,401,529)-9)%529==17*23

N=20240
modulus=128*11*17*23**2
assert pow(25,N,modulus)==pow(9,N,modulus)==1
for t,lo,hi in ((25,F(50),F(470,9)),(19,F(38),F(118,3))):
    assert 13-7*t in (-162,-120)
    limit=F(2*N*t,3**9)
    assert lo<limit<limit+F(2*(13+3*N*t),3**15)<hi
    for j in (6,7):
        e=3*(j%2)
        u=13+N*t*(3**j+e)
        v=7+N*(3**j+e)
        assert u>v and u%2==v%2==1 and gcd(u,v)==1
        assert lo<F(2*u,3**(j+9))<hi
        assert (pow(25,u,modulus)-pow(9,v,modulus))%modulus \
               ==(25**13-9**7)%modulus

A,S=5**231,3**131
assert A>S and gcd(231,131)==1
P=[p for p in range(2,20001,3)
   if all(p%d for d in range(2,isqrt(p)+1))]
assert all(val(A*A-S*S,p)%2==0 for p in P)
H=(A-S)//(2*17**2)
assert 2*17**2*H==A-S and H%17
e=H-1
while e%3==0:
    e//=3
z=pow(5,e,H)
assert (z*z+z+1)%H==0
r=(2*z+1)%H
a,x=H,min(r,H-r)
while x*x>H:
    a,x=x,a%x
y=isqrt((H-x*x)//3)
assert x*x+3*y*y==H
assert (17*x)**2+3*(17*y)**2==(A-S)//2
J=(A+S)//8
assert 8*J==A+S and pow(2,J-1,J)!=1
assert all((pow(25,231,23)-pow(9,v,23))%23
           for v in (13,31,131,149,295))
print("PASS")
```
