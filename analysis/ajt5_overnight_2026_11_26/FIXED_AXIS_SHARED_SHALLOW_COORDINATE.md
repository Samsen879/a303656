# 共享浅阶位与未读轴修复

**厚阶行有时可以保留原来的冻结位，通过两轴共享浅读坐标接入无阻断图。** 在真实的 \(20771\) 对照中，保留上一轮的 \(d\bmod5=0\) 及整段余因子相位后，31 个 \(d_{31}\) 数字只禁一个。选好 \(d_{31}\)，就能让 \(20771\) 对所有 \(c_{31}\) 都保持单位，再用 \(c_{31}\) 修复素数 \(31\)。

### 共享一位的算术条件

记 \(o_b(p)=\operatorname{ord}_p(b)\)。设奇素数 \(r\) 在 \(o_3(p),o_5(p)\) 中都恰出现一次。固定两个指数在各自余因子 \(o_b(p)/r\) 上的相位。这样 \(3^c,5^d\bmod p\) 分别遍历两个陪集 \(AH,BH\)，其中 \(H\) 是模 \(p\) 的阶 \(r\) 子群。

可直接计算须禁掉的 \(d_r\) 数字。它们对应
\[
BH\cap(n-AH).
\]
选在交集以外后，\(p\) 对**所有** \(c_r\) 都保持单位。若 \(n\not\equiv0\bmod p\)，交集不可能有 \(r\) 个元素，因为两集合的元素和分别是 \(0\) 和 \(rn\)。若 \(r\ge5\)，交集至多有 \(r-2\) 个元素。否则设两集合各自唯一缺失的元素为 \(x,y\)，比较一、二、三次幂和，得到
\[
y-x=rn,\qquad y+x=n,\qquad y^2+xy+x^2=n^2.
\]
消元给出 \(r^2\equiv1\bmod p\)，与 \(1<r<p-1\) 矛盾。因此一条这样的共享行，即使再加一条普通首位禁类，仍留有容量。

零类有一个精确边界。若 \(n\equiv0\bmod p\)，交集在 \(BH=-AH\) 时是整个陪集，否则为空。真实例子是 \(p=31\)、\(r=3\)、\(n\equiv0\bmod31\)、\(c\equiv5\bmod10\)。此时 \(3^c\) 遍历 \(-\langle5\rangle\)，每个 \(d_3\) 都允许某个 \(c_3\) 造成碰撞。这条共享单位路线因此无法使用，但 \(31\) 仍可作普通提升。

### 容量与未读修复合成的整面板判据

对给定有限面板，先选定 \(c,d\) 的有限余类和一组受保护行。保护可以来自已核验的偶赋值、固定 \(3^c\bmod p\) 后分配的单个 \(d\) 阶坐标，或上面的两轴共享。逐坐标检查所分配禁类的并集没有用尽该坐标的允许球。普通单坐标任务若满足 \(o_5(p)=rm,\ m\le M,\ r\nmid m\)，可用分圆乘积界控制其容量。共享任务计入实际禁掉的 \(d_r\) 数字。若某位已部分固定，须在其实际允许球内计算余量。

保护条件中预先锁定的余因子位、允许球和偶赋值证书也一并计为读集；所选数字须同时满足坐标间的依赖，而不能仅按各坐标孤立地计算容量。

然后检查每个未保护的惰性 \(p>5\)。**只要至少有一轴在 \(p\) 上是普通的，且该轴的 \(p\) 主坐标未被保护条件读取，整张面板就可通过。** 按素数递增处理这些行。遇到碰撞时，普通底在自由的自身主坐标上提供全部下一位，可以把余数选到精确赋值 \(2\)。较小素数不读该坐标；受保护行的条件也继续成立。\(2,3,5\) 单独核验后，有限 CRT 把这些选择兑现为模解。 [双增长有限面板及局部提升](https://github.com/Samsen879/a303656/blob/67fde350af013a3183e4e7ec6411a016522b7ad6/analysis/ajt5_overnight_2026_11_26/SINGLE_WITNESS_FINITE_OBSTRUCTIONS.md)

因此，一张真正的全指数阻断面板，必须对每个容量可行的保护方案留下至少一个未保护惰性素数，其两轴均异常或各自的修复坐标均被读住，亦可是一轴异常、另一轴被读住。仅发现某条阶边不够薄，还没有得到这种障碍。

### 同一 \(n\) 上保留冻结位的复验

沿用 \(N=301491668318363121843280379\)，取 \(q=20771,\ r=31\)。两底在 \(q\) 的实际阶均为 \(335\cdot31\)。固定 \(c\equiv0\bmod335,\ d\equiv5\bmod335\)，所以旧路线被冻结的 \(d\bmod5=0\) 保留。共享检验只禁 \(d_{31}=5\)。取 \(d_{31}=0\) 后，若仍把 \(c=0\)，则 \(31\) 处余数有精确赋值 \(1\)。改用未读的 \(c_{31}\) 修复，得到下面的局部相位：

```python
N, q, r = 301491668318363121843280379, 20771, 31
H = {pow(3,335*j,q) for j in range(r)}
assert len(H) == r
assert H == {pow(5,335*j,q) for j in range(r)}
assert {(5+335*j) % r for j in range(r)
        if (N-pow(5,5+335*j,q)) % q in H} == {5}

c, d = 5719569570, 252101027975
assert (c % 335, d % 335, d % 5) == (0,5,0)
assert (N-1-pow(5,d,31**2)) % 31**2 == 22*31
for m, expected in ((4,1),(27,18),(11**3,11**2),
                    (31**3,31**2),(67**3,67**2),(q,19407)):
    assert (N-pow(3,c,m)-pow(5,d,m)) % m == expected
```

这里 \(q\) 的底 \(3\) 是普通的，所以例子检验共享机制，无需假设存在共同 Wieferich 终点。大指数 \(c,d\) 只给出局部相位。同一 \(N\) 的实际真表示仍是 \(3^2+5^0+53636783280^2+17363432593063^2\)。

尚未证明任意厚阶异常面板都有容量可行且留有未读修复轴的方案。新判据把这个缺口定位在实际阶的读集与共享禁类上。
