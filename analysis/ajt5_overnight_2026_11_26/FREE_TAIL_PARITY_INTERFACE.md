# Two parity phases for a free-height shared 3-adic tail

Fix finitely many labelled actual roots of the form $K_i(t)=a_i+b_i3^t$, where $b_i$ is either $3^h$ or $5\cdot3^c$ with nonnegative integer $h,c$. Set $D=\max_{a_i\ne a_j}v_3(a_i-a_j)$, or zero if all constant terms coincide. For each $t$ consider the set of full labelled masks of odd valuations $v_3(x-K_i(t))$ attainable over integers $x>\max_i K_i(t)$. One may also require $5\mid x$. This set of masks is the same at $t$ and $t+2$ whenever $t\ge D+2$.

To see this, first examine the residue of $x$ modulo $3^{D+1}$. The distinct constant-term clusters have distinct residues there and the roots in each cluster still share their old residue. If $x$ is outside every cluster, every valuation is at most $D$ and is independent of $t$. If it is inside the cluster of $a$, then valuations outside that cluster are fixed by the differences of constant terms. Inside, an exit at depth $j=v_3(x-a)<t$ gives valuation $j$ on every cluster label. Deeper values have the form $x=a+3^t y$ and give valuations $t+v_3(y-b_i)$. This inner set of patterns depends only on the parity of $t$. The exit depths include $D+1$ as soon as $t\ge D+2$, and any added depths can contribute only the two uniform parity masks. At the earliest possible $t=D+2$, the other parity is already supplied inside by $y=10$: $v_3(10-b_i)=2$ if $b_i=1$, and zero otherwise. Every finite valuation pattern can be translated above all roots while preserving it by adding a sufficiently high power of 3, with the multiplier also chosen to impose the optional congruence modulo 5. This proves equality of free attainable mask families, not equality at the same $x$ or in a bounded height window.

The head cannot be discarded just by parity: actual roots $5+3^t$ and $5+5\cdot3^t$ at $t=0$ give $6,10$, so neither common residue can hit both mod 3. At $t=2$ they give $14,50$, and $x=65$ gives residuals $51,15$ with exact valuation one on both. Same parity alone is not a valid compression before the threshold.

## Fixed-period compatibility interface

Separately, suppose local permissible phases are subsets of residues modulo fixed periods $L_i$. For each slot define $D_i=\gcd(L_i,\operatorname{lcm}_{j\ne i}L_j)$ (empty lcm 1). Keep the residue modulo $D_i$ of each phase and the whole nonempty fibre of permitted states. This is sufficient for deciding shared-exponent feasibility: $\gcd(D_i,D_j)=\gcd(L_i,L_j)$ by comparing prime exponents, so any representatives of chosen compatible fibres meet exactly the same pairwise generalized-CRT conditions. Moreover, if two residues distinct modulo $D_i$ are identified, fixing all other slots to one of the original residue's phases can distinguish feasibility, because some common pairwise modulus sees the difference. This is a minimal universal modulus interface for that fixed list, not a claim about newly added periods, root labels or actual norm witnesses.
