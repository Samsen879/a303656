# Full-product multi-source rational fusion no-go

**MF-R** is a proved negative structural theorem for rational identities over
the original `Q`-function field of a fixed finite independent product of
parallel two-square source conics. It says that a new monic linear residual
`X-T` cannot be produced identically; source offsets are the only targets.

- [Scope and boundary examples](SCOPE.md)
- [Reproduction](REPRODUCE.md)
- [Source custody and authority chain](SOURCE_CUSTODY.md)

Relative to PF-N-002 Q, PF-N-003 Q*, and PF-N-004 Q-dagger, MF-R permits
arbitrary rational degree and multiple sources, but addresses only a
full-product identity for a monic linear target. Those earlier results concern
one-source chart images and witness-continuous recursion with separate
arithmetic counting hypotheses. Thread 4 C5 treats fixed-affine real-algebraic
two-source identities; MF-R treats arbitrary rational functions and any fixed
finite number of sources over the original `Q`-function field. None of these
results is replaced by MF-R. A303656 remains **UNRESOLVED**.
