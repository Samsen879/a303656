# Coprimality refinements for the two simultaneous mixed meshes

The entire all-\(J\) construction of [#101](https://github.com/Samsen879/a303656/pull/101) works with both extra conditions
\[
\gcd(S,D_i)=\gcd(q_{i,j},D_i)=1\quad(i=1,2;\ 0\le j<m),
\]
where \(S=N(P)\), \(D_1=D=50B-A\), \(D_2=E=62B-13A\), and \(q_{i,j}=N(R_{i,j}-P)/2\). The same preselected rotations and bins, the original budget and the count of distinct constructed targets remain valid.

Both \(D,E\) are coprime to 30, and \(13D-E=588B\), so \(\gcd(D,E)\mid49\). At any \(p\mid DE\), the polynomial \(S(t)\bmod p\) has degree four with leading coefficient \(125B/2\ne0\); it excludes at most four parameter classes. The forcing moduli and \(B\) are coprime to \(DE\) as shown in #101. If \(p\le4m\), the fixed rotations act as identity modulo \(p\), and the raw chords never vanish, so these four exclusions give all the constraints. If \(p>4m\), then \(p\) divides only one of the two half-differences. The other edge's chords cannot vanish modulo \(p\), since their norm difference is \(2D_i\). The \(m\) selected chords of the relevant edge forbid at most two classes each, by the existing quadratic argument. The total is thus at most \(2m+4\le4m<p\) for the main \(m\ge8\). For every prime the same list \(0,\ldots,4m\) contains an admissible parameter; no re-selection of rotations is needed.

Implement this in the same prime-power-block CRT by including \(\gcd(R,N(U(t)))\) with the chord gcds at each candidate, where \(R\mid DE\) is the remaining modulus and \(U=2\bar\rho P\). Since \(N(U)=4BS\) and \(4B\) is a unit there, this enforces exactly the added condition modulo every relevant prime. Assign to the full prime powers as before; the total modulus and height estimates are unchanged.

For a selected chord \(d=R_{i,j}-P\), \(N(d)=2q\) and \(P\cdot d=D_i-q\). If \(p\mid D_i,q\), then \(d\) is orthogonal to \(P\) over \(\mathbb F_p\) and has norm zero. Since \(N(P)=S\ne0\bmod p\), the orthogonal line is generated by \((-P_y,P_x)\), whose norm is \(S\ne0\). Thus \(d=0\bmod p\), contradicting primitivity. This works for split as well as inert primes. All selected chords therefore satisfy the required two gcd conditions.

## Independent native replay

The first target is the exact \(s=42,K=4029\) eight-endpoint control in #101. The second changes only the parameter condition at 97; the same bins remain occupied and all chords remain primitive, but \(\gcd(S,D)=97\). This separates source coprimality from chord primitivity and from \(\gcd(q,D_i)=1\).

```python
from math import comb, gcd, isqrt, prod
s,K=42,4029
A,B=9**s,25**s
r=sum(comb(2*s,j)*2**(2*s-j)*(-1)**(j//2) for j in range(0,2*s+1,2))
z=sum(comb(2*s,j)*2**(2*s-j)*(-1)**((j-1)//2) for j in range(1,2*s,2))
assert r*r+z*z==B
H=(A+125*B,3*A+25*B,27*A+B)
D,E=((H[0]-H[i])//2 for i in (1,2))
pack=((1,0,4786648,-105,4166402983095),(1,1,2233760,-49,4203548683733),
      (1,2,3191071,-70,268576829947),(1,3,5424800,-119,15962826517306),
      (2,0,2871850,-63,2913516008210),(2,1,2233654,-49,1937840990991),
      (2,2,4786382,-105,21199354421098),(2,3,4467275,-98,12010672491224))
I=r*pow(z,-1,B)%B
cs=[(0,2),(0,D*E),((38-12*I)*pow(3-I,-1,B)%B,B)]
cs.extend((c,a*a+b*b) for _,_,a,b,c in pack)
M=prod(m for _,m in cs)
rr=sum(c*(M//m)*pow(M//m,-1,m) for c,m in cs)%M
T=isqrt(isqrt((1<<K)//B))
lo=(3*T+7)//8
t0=lo+(rr-lo)%M
assert lo<=t0<2*T//5
bins=[p[:4] for p in pack]
P = 2*B*prod(a*a+b*b for _,_,a,b in bins)
N = D*E
assert D%97==0 and E%97!=0
while N%97==0:
    N//=97
step = P*N
t1 = t0+step*((17-t0)*pow(step,-1,97)%97)

for t, expected, tag in [(t0,(1,1),302651486),(t1,(97,1),745323225)]:
    u = A*(3*t-38)+B*(-15*t*t-147*t+138)
    v = A*(-t+12)+B*(5*t*t+49*t-16)
    x, ex = divmod(r*u-z*v,2*B)
    y, ey = divmod(z*u+r*v,2*B)
    assert ex==ey==0
    S = x*x+y*y
    n = H[0]+S
    assert B**16<n<A**32 and 2**K<=S<2**(K+1) and n%8==6
    assert (gcd(S,D),gcd(S,E))==expected and n%1000000007==tag
    for i,j,a,b in bins:
        l,m = (1,3) if i==1 else (t+1,3*t+1)
        X,Y = x+r*l-z*m,y+z*l+r*m
        M,c,d = a*a+b*b,a*a-b*b,2*a*b
        xx,f = divmod(c*X+d*Y,M)
        yy,g = divmod(c*Y-d*X,M)
        assert f==g==0 and xx*xx+yy*yy==n-H[i]>0
        dx,dy = xx-x,yy-y
        assert dx%2==dy%2==gcd(dx,dy)==1
        q = (dx*dx+dy*dy)//2
        k = (8 if i==1 else 20)+j
        assert gcd(q,(D,E)[i-1])==1
        assert k*S<32*(64*K*K*(K+1)*q-K*S)<(k+1)*S
print("OK")

```
