# What is disproved, and what is not

| Claim | Finding | Domain |
|---|---|---|
| R(n)>=eta G(n) for one fixed eta>0 and all large n | False by K2-N1 | Actual original-n problem, conditional on accepted K lower bound |
| R(n)>=kappa G(n)/(log n)^beta, beta<1/2 | False by the same counting argument | Actual original-n problem |
| N_p^G<=C G/[p(log p)^alpha] uniformly, no additive error | False by K2-N2 | Infinite literal family n=pq+2 |
| B_pq<=C G/(pq) uniformly, no additive error | False by the same literal atom | Infinite literal family |
| Absolute errors for smooth ordinary local model can sum to o(G) up to polynomial n | False by K2-N3(a) | Explicit comparable-density absolute-remainder template |
| Fixed log-alpha least-prime conditioning makes those absolute errors o(G/log n) | False by K2-N3(b) | Explicit least-prime model template |
| Tiny individual prime fibers imply tiny total union | False as a combinatorial inference | Non-literal all-failing incidence model |
| Same Phase K local cell forces an individual residual to be a norm | False | Supplied literal pair at c=3,d=2 |

Not disproved: A303656, pointwise R>0, the old LC-K exponent 1/2, ML-K2, an actual
large-prime range-total theorem, signed cancellation, adaptive arithmetic weights,
or a method exploiting further literal common-n structure. None of these is
proved by the negative results either.
