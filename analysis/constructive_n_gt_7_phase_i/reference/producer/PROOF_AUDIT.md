## Mathematical checks

**No premature loss of guards.** Terminal peeling uses only coordinates with fewer sources than the coordinate prime. All periods, original rows, and states remain frozen; no nonlinear origin-count assertion is extended past its valid sparse range.

**No unit-capacity extrapolation.** N controls pre-nonlinear sources. The source's post-nonlinear capacity is the width of frozen provider cylinders in one witness. Extra origins may change parity roles without supplying spare slots in the same witness.

**No illegal sharing.** Actual modules20771 and40487 share the same r31=4. N9's three conditional roots share this same helper state, while their final depth-two exact providers are the three distinct origins themselves. No derived macro is placed in an original row slot.

**One state, universal exponent.** Canonical a-values specify row states once. They are not freshly chosen for each tested exponent. Different module a-values are allowed precisely when overlapping original row residues agree.

**Universal profiles.** A union of individually saturated profiles is only a sufficient positive guarantee in general. For the actual partial ledger, the exact saturated union is checked separately using all private equality/non-equality patterns. Independent-block factorization is not assumed for overlapping modules.

**Correct lifting at an even regular relay.** For p=258065887, w_p=186 and s_p=1, so 5^93 is NOT inferred to be -1 modulo p². The canonical log also has private center0, giving exponent93p modulo186p. It is 5^(93p)=-1 modulo p² that justifies residue2. The direct verifier checks the actual residue recipe.

**Local zero.** At the stored actual escape, the67-row even has zero modulo67². That zero remains nonfatal, as required. Mutating this rule is rejected.

**BOTH, not EITHER.** Anchor0 is covered by r2=1 mod4 everywhere. A1 failure therefore supplies an explicit example with EITHER true and BOTH false. No pooled cover is upgraded to simultaneous completeness.

**Counts versus density.** Zero/nonzero quotient cells have different multiplicities. The package separately records cell counts, pointwise full-period density, and whole-private-fiber boundary density.

**Composite is not repeated.** C279's Fermat witness proves compositeness only. No factor<=10000 proves no small factor only. Neither is used as a square-part result.
