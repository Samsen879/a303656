# A joint obstruction for a fixed finite list of balanced strict anchors

先冻结任意非空有限偏移表 \(F\subset\mathbb Z^2\)。按 [#121 的严格平衡定义](https://github.com/Samsen879/a303656/pull/121/files)，令
\[
r_-=\max_{(i,j)\in F}\frac{3^i}{5^j},
\qquad
r_+=2\min_{(i,j)\in F}\frac{3^i}{5^j}.
\]
若 \(r_-<r_+\)，则对每个固定 \(K>0\)，存在无穷多个实际指数对 \((u,v)\) 和对应的同一目标 \(n\)，使得对 **每个** \((i,j)\in F\)，以 \(A_i=3^{u+i}, B_j=5^{v+j}\) 为锚：

- \(A_i<B_j<2A_i\)，且 \(n>K\cdot900 A_iB_j\)。
- 严格陪集 \(\mathbb Z^2\times A_i(1+30\mathbb Z)\times B_j(1+30\mathbb Z)\) 对 \(X^2+Y^2+3U^2+5V^2=n\) 在每个素数处本原可解，九个中央分支的余量均为正。
- 该陪集中没有整数解，而同一个 \(n\) 有显式的 Sun 表示。

若 \(r_-\ge r_+\)，同时严格平衡已经不可能，因为它等价于 \(r_-<B/A<r_+\)。例如，相邻对角偏移 \((0,0),(1,1)\) 可行，要求 \(1<B/A<6/5\)；单轴偏移 \((0,0),(1,0)\) 不可行。

### 同一目标的联合 CRT

在 \((r_-,r_+)\) 内先固定一个闭区间 \([\ell,h]\) 和一个正的 \(12\) 的倍数 \(a\)。构造
\[
n=(aB+S)^2+T^2+A^2+B^2,\qquad A=3^u,\quad B=5^v .
\]
最后取 \(0\le S,T<B\)。于是
\[
a^2\le n/B^2\le M_a:=(a+1)^2+2+\ell^{-2}.
\]
先把 \(a\) 选大，使其平方超过所有锚的中央九分支贡献上界
\(31^2(3(3^i/\ell)^2+5(5^j)^2)\)，以及所有 \(K\cdot900\,3^i5^j/\ell\)。任何余量非负的分支必在以下有限盒内：
\[
3(3^i/h)^2(1+30z)^2\le M_a,\qquad
5(5^j)^2(1+30w)^2\le M_a.
\]

取固定的基准指数 \(u_0,v_0\)，使所有偏移指数非负且 \(u_0\ge1\)。在每一盒行，将 \(A,B\) 代成 \(A_0=3^{u_0},B_0=5^{v_0}\)，定义
\[
d=A_0^2+B_0^2
  -3\bigl(3^{u_0+i}(1+30z)\bigr)^2
  -5\bigl(5^{v_0+j}(1+30w)\bigr)^2 .
\]
**每行都有 \(d\equiv2\bmod8\)，故 \(d\ne0\)。** 为该行选一枚尚未使用的 \(p>5,\ p\equiv3\bmod4,\ p\nmid d\)。模 \(p\) 的两个平方值集合各有 \((p+1)/2\) 个元素，所以可解 \(x^2+y^2=-d\)，且至少一坐标为单位。沿该坐标提升一步，得到
\[
x^2+y^2+d\equiv p\pmod{p^2}.
\]
在此 \(p^2\) 上要求 \(S\equiv x-aB_0,\ T\equiv y\)。全盒一次 CRT，再加 \(S,T\equiv0\bmod12\)，给出固定的非负 \(S,T\)。两条可调平方坐标使选素数只需避开 \(d\) 的素因子。惰性素数的无穷性用 \(4P-1\) 的欧几里得论证即可。

令 \(P\) 为各证书素数的 \(p(p-1)\) 的公倍数。取 \(u\equiv u_0,\ v\equiv v_0\bmod P\)，则所有锚的实际幂在对应 \(p^2\) 上保留基准值。由 \(\log5/\log3\) 无理，其整数倍的分数部分稠密，故在这些指数类内仍可令 \(B/A\in[\ell,h]\) 且 \(A,B\to\infty\)。最终 \(S,T<B\)，每个盒行的实际余量都有指定素数的赋值恰为一，连零余量也被排除。

### 局部条件的精确范围

所有这些严格陪集在有限素数处共同本原可解的目标条件恰为
\[
n\bmod8\in\{0,1,2,4,5\}.
\]
在 \(2\) 处，\(U,V\) 都为奇数，其加权平方和为 \(0\bmod8\)，所以该条件必要。反过来，先选 \(X,Y\) 给出所需模 \(8\) 余数，固定 \(V=B_j\)，再从 \(1\bmod8\) 的单位中取 \(U\) 的奇平方根。每个奇数都属于所需的 \(2\)-进第三坐标类。

在 \(3\) 处，先选 \(X,Y\) 模 \(3\) 使其平方和为 \(n-2\)，固定 \(U=A_i\)，再沿 \(V/B_j\equiv1\bmod3\) 提升平方根，\(V\) 为单位。在 \(5\) 处固定 \(U,V\)，用 \(-1\) 的平方根把 \(X^2+Y^2\) 写成两个线性因子的乘积，并令其中一因子为 \(1\)。在 \(p>5\) 处，两坐标步长均为单位，取 \(U=0,V=1\bmod p\)，解两个平方的余数后沿 \(V\) 提升。构造的目标统一满足 \(n\equiv10\bmod24\)。

**最弱环节。** 证明为整个有限盒逐行配素数，CRT 周期随偏移表与 \(K\) 增长。所得量词是先冻结偏移表和 \(K\)，再构造目标。它不控制随目标增长或自适应选择的锚表。

### 两个实际相邻锚的整数重放

同一目标 \(49\,443\,588\,422\,768\,273\,818\) 的 Sun 表示为
\[
7\,031\,312\,196^2+138\,456^2+3^{32}+5^{22}.
\]
两锚为 \((16,11),(17,12)\)，分别有 \(22,3\) 个活跃分支。这个有限对照要求每锚至少三个活跃分支，上面的无穷族保证每锚九个中央分支。

```python
from math import isqrt

A, B = 3**16, 5**11
x, y = 144*B + 62196, 138456
n = x*x + y*y + A*A + B*B
assert n == 49443588422768273818 and n % 24 == 10
P = iter([75011,47,11,23,131,239,11,9395131,510463,419,163,23,
          27539,47,11,11,367,31,43,107,103,23,47,31,43])
counts = []
for i,j in ((0,0),(1,1)):
    a,b = A*3**i, B*5**j
    assert a < b < 2*a and n > 900*a*b
    m,k = isqrt(n//3)//a, isqrt(n//5)//b
    count = 0
    for z in range(-((m+1)//30),(m-1)//30+1):
        for w in range(-((k+1)//30),(k-1)//30+1):
            R = n-3*(a*(1+30*z))**2-5*(b*(1+30*w))**2
            if R < 0:
                continue
            p = next(P)
            assert p%4 == 3 and all(p%d for d in range(2,isqrt(p)+1))
            assert R%p == 0 and R%(p*p) != 0
            count += 1
    counts.append(count)
assert counts == [22,3] and next(P,None) is None
print(n, counts)
```

实跑输出 `49443588422768273818 [22, 3]`。
