# Adversarial scope audit

This is an internal audit by the same research session, not independent review.

| Attack | Resolution / boundary |
|---|---|
| Per-cell or per-fiber re-selection of residues | One global row-state token is fixed; C8 uses one frozen regular escape trace. |
| EITHER silently becomes BOTH | Six truth functions and separate universal elimination formulas are retained; SPLIT leaves BOTH unchanged. |
| Higher regular rows might kill an earlier escape | C6 constructs a safe center at every later coordinate for every existing safe prefix. |
| Dynamic q could cover a missing rigid logarithm | On that guard, q has a safe full center; difference 2 forbids another simultaneously active anchor. |
| Deep prime-power support could still have a one-point trace | Valuation 2 is never accepted; every second lift over the first center digit has some common-safe full lift. |
| Omission of accepted valuation 1 is harmless | It permits all first digits and violates the two-point trace bound. The fixed-E theorem includes this gate. |
| A nonregular row is automatically a usable rigid row | C9 separately requires an accepted odd h<s_q; mere s_q>=2 is insufficient with fixed E. |
| The P5 converse conflicts with the P5 construction | C9 reconstructs the source h=1,K=2 case and extends it to r_q=q^h+2 with arbitrary fixed K. |
| Generalized P5 identifies U and L | It does not. Its proof is for every integer exponent; U=L is only a special source construction fact. |
| Additional fixed residue restrictions are ignored | C9 sufficiency requires unrestricted residue rings. Restricted state families use C8 and integer feasibility. |
| A new original coordinate is inserted without actual support | The actual LP example includes regular support rows 43 and 1303; the skeleton's U=6 is separately stated. |
| Fractional existence is promoted to actual coverage | All 5859 integer choices fail; the fractional witness is explicitly a counterexample to relaxation sufficiency. |
| Pairwise common-residue checks imply all-use consistency | C3 supplies the exact next-digit condition and an actual pairwise-compatible/three-way-incompatible example. |
| Every cross-fiber row reuse is a collision | Y=7,162 with q20771 is verified compatible; only q-relevant incompatible guards or positions collide. |
| q divides several resultants, so its states can be synchronized | q20771 at Y=7,8 is a counterexample; lower-order divisibility must be checked first. |
| Resultant divisibility need not yield roots in the base field | C5 also enforces exact h-divisible order; the relevant polynomials then split completely over F_q. |
| Resultant multiplicity is confused with nonregularity | C5 uses q^2 divisibility of the cyclotomic quotient separately from q divisibility of the resultant. |
| OR alternatives become simultaneous suppliers | C2-C5 apply only to genuinely required, selected original uses; the general forcing bridge is not proved. |
| Macro depth is used as arithmetic order depth | Prohibited: all C2/C4/C5 inputs are original ranks, original order depths and actual logarithms. |
| One/two nonregular simultaneous no-go is presented as new | It is attributed to the existing seven-nonregular theorem; new classification concerns odd pooled EITHER. |
| A P5 seed or complete actual odd cover has been found | Neither is claimed. H membership is an exact criterion for a supplied actual q, not a proof that some such nonregular q exists. |
| Small exact tests prove the unbounded theorems | They do not; C6-C9 have symbolic proofs independent of the tables. |
| Same-environment cross-checks are called independent software stacks | Not claimed. Bareiss/Euclid and paired enumerations are differently organized reference checks. |
| Local scope becomes a result about n=a^2+b^2+3^c+5^d | Not claimed; the formalism-to-original-problem bridge is not supplied. |

Highest-value independent review targets are C7's prefix-extension quantifiers,
C8's treatment of a mixed dynamic/rigid terminal row, C9's fixed-E sufficiency,
and C5's original-depth/potential-position scope. The reference package leaves
project authority unchanged regardless of these research deductions.
