# C=1 minimal saturated odd-coordinate inverse classification

This directory integrates the targeted Phase A study of the necessary coordinate condition

```text
D_(l,c)+R_(l,c) >= 1.
```

The work separates abstract rational saturation, exact `l`-adic fiber coverage, and arithmetic realizability. Its main theorem is an exact parameterized classification of fiberwise irredundant covers by one centered rigid cylinder and independent complete prefix-code frontiers. A complete admitted coarse certificate would force one such actually covered odd fiber during increasing-coordinate greedy selection.

## Principal statements proposed for audit

1. **Atomic rational classification.** Every atom-minimal genuine saturation has total exactly one and obeys an exact deficit recurrence; its largest denominator depth is at most the atom count minus one.
2. **Two-row equality.** Odd-valuation parity makes the beta-one dynamic shell plus one centered rigid digit the unique admitted two-row equality pattern.
3. **Centered prefix-frontier inverse theorem.** Every fiberwise irredundant full cover has exactly one rigid cylinder containing the unresolved center; all remaining rigid rows form complete prefix frontiers in unaccepted side branches. Accepted dynamic tail shells inside the centered cylinder are the only overlaps.
4. **Complete-certificate witness.** Increasing-coordinate greedy avoidance implies that any complete admitted coarse certificate must contain an actually covered odd-coordinate fiber, hence one parameterized centered prefix-frontier template.
5. **Arithmetic gate.** Abstract templates remain subject to order divisibility, nonregular-prime supply, lifting depth, common-residue compatibility, both-anchor compatibility, and fail-closed local-zero requirements.

Reviewers should especially audit the greedy actual-fiber witness, the distinction between a fiberwise irredundant subcover and global row deletion, the canonical center lift when `m<beta`, and parameter-labelled versus unlabelled template counts.
