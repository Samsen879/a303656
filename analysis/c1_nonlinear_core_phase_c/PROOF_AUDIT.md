The most important independent audit target is T1 → T2: whether the chosen macro grammar and scope really guarantee the same original logarithm shadow in every parent citing q. If arbitrary domain restrictions or independently coloured shadows are silently added, the private-provider theorem can no longer be applied as written.

The remaining mathematical barrier is not hidden: no proof charges all private regular helper providers injectively (or with sufficient bounded congestion) to original nonregular seed origins. A finite TRUE terminal is compatible with all the purely structural invariants proved here.
